# Contributing

Run `python -m pip install -e '.[test]'`, `python -m pytest tests -q` and `python examples/first_run.py`. Start with the pilot or a synthetic regression case. No private project access is required.

Describe the question, input contract, expected result and actual behavior. Preserve unknown metadata as unknown. Do not infer aliases, adjudicate scientific truth automatically, or turn a successful software check into evaluation approval. Any change to report schemas needs a compatibility note and tests. Keep modules independently callable and avoid new runtime dependencies without a demonstrated need.

Submit a pull request with tests and limitations. Disclose AI assistance and verify it yourself. Contributions to this package use MIT; retain third-party attribution. Never post patient data, credentials or correspondence in issues. Maintainer review is required for merging. No review deadline, publication authorship or paid role is promised.

Accepted work retains Git attribution. Public credit preferences can be recorded in the issue. Maintainers should link each accepted pilot report to the change it influenced. Respect contributors; criticize assumptions and evidence, not people.
